Erendra เป็นเกมผจญภัย 3 มิติในเมือง **Verdelon City** เมืองที่เคยอยู่ร่วมกับธรรมชาติอย่างสงบ แต่ถูกทำลายจากมลพิษและความละเลยของผู้คน

ผู้เล่นจะออกเดินทางร่วมกับเป็ด NPC เพื่อช่วยชาวเมือง ทำความสะอาดพื้นที่ กำจัดมอนสเตอร์ขยะ และฟื้นฟูต้นไม้แห่งชีวิต **Erendra** ให้กลับมาแข็งแกร่งอีกครั้ง

## แนวคิดและเวทีการแข่งขัน

เกมนี้พัฒนาขึ้นสำหรับรายการ **Thailand-Japan Programming Game Hackathon** โดยนำแนวคิด **SDG 11: Sustainable Cities and Communities** มาเป็นแกนหลักของเกม

เนื้อหาของเกมสะท้อนการสร้างเมืองและชุมชนที่ยั่งยืน ผ่านการจัดการขยะ การดูแลสิ่งแวดล้อม และความร่วมมือของผู้คนในชุมชน เพื่อฟื้นฟู Verdelon City ให้กลับมาน่าอยู่และมีชีวิตอีกครั้ง

## เรื่องราว

เมือง Verdelon City กำลังเสื่อมสลาย และต้นไม้แห่งชีวิต Erendra ก็อ่อนแอลงเรื่อย ๆ ผู้เล่นต้องค้นหาความจริงของเมือง รับภารกิจจากผู้คน และช่วยกันเปลี่ยนพื้นที่ที่เต็มไปด้วยขยะให้กลับมามีชีวิตอีกครั้ง

## รูปแบบการเล่น

### 1. สำรวจเมือง

เดินทางไปรอบ ๆ เมืองเพื่อค้นหาพื้นที่สำคัญ ตัวละคร และภารกิจใหม่ ๆ

### 2. พูดคุยกับ NPC

เข้าใกล้เป็ด NPC แล้วคลิกเมาส์ซ้ายเพื่อเริ่มบทสนทนา กด **Next** เพื่ออ่านเรื่องราวและรับภารกิจ

### 3. ทำความสะอาดเมือง

เก็บขยะในพื้นที่ให้ครบ เพื่อปลดล็อกเส้นทางไปยังภารกิจถัดไป

### 4. กำจัดมอนสเตอร์ขยะ

เข้าใกล้มอนสเตอร์แล้วคลิกที่ตัวมันเพื่อโจมตี เมื่อพลังชีวิตหมด มอนสเตอร์จะถูกกำจัด

### 5. ฟื้นฟูต้นไม้ Erendra

ทำภารกิจตามคำแนะนำของ NPC จนได้รับ **holy water** จากนั้นนำไปยังต้นไม้ Erendra เพื่อช่วยฟื้นฟูเมือง

## การควบคุม

| ปุ่ม | การทำงาน |
| --- | --- |
| `W` `A` `S` `D` | เดิน โดยอ้างอิงทิศทางของกล้อง |
| ปุ่มลูกศร | เดิน |
| `Space` | กระโดดเมื่ออยู่บนพื้น |
| คลิกซ้าย | คุย, อ่านบทสนทนาต่อ หรือโจมตีศัตรูที่อยู่ใกล้ |
| `P` | หยุดเกมหรือเล่นเกมต่อ |

## เป้าหมายหลัก

> **ทุกชิ้นขยะที่เก็บได้ คืออีกหนึ่งก้าวในการช่วยเมือง Verdelon City และต้นไม้แห่งชีวิต Erendra**

- สำรวจเมืองและติดตามเรื่องราว
- ช่วยเป็ดและชาวเมืองทำความสะอาดพื้นที่
- กำจัดมอนสเตอร์ขยะ
- นำ holy water ไปฟื้นฟูต้นไม้ Erendra
